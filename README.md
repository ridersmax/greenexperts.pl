# GreenExperts — strona publiczna

Statyczna strona przygotowana dla GitHub Pages i domeny `greenexperts.pl`.

Formularz wyceny wysyła zgłoszenia do GreenExperts CRM przez publiczny endpoint
`POST /api/public/leads`. Główny adres to `https://crm.greenexperts.pl`, a adres
Render jest używany jako bezpieczne połączenie zapasowe.

Przed publikacją należy uzupełnić pełny numer telefonu, dane rejestrowe firmy,
e-mail oraz zatwierdzić politykę prywatności.
