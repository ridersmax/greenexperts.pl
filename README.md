# GreenExperts — strona publiczna

Statyczna strona przygotowana dla GitHub Pages i domeny `greenexperts.pl`.
Oferta publiczna jest kierowana do właścicieli domów, wspólnot i małych firm
z Zielonej Góry oraz całego województwa lubuskiego.

Formularz wyceny wysyła zgłoszenia do GreenExperts CRM przez publiczny endpoint
`POST /api/public/leads`. Główny adres to `https://crm.greenexperts.pl`, a adres
Render jest używany jako bezpieczne połączenie zapasowe.

Po uzyskaniu danych należy uzupełnić w `polityka-prywatnosci.html` i `regulamin.html`
pełny adres działalności, NIP oraz adres e-mail administratora / do reklamacji.
Te same pola występują w wersjach `en/` i `de/`. Numer telefonu jest już uzupełniony.
